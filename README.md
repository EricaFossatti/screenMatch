# ScreenMatch
Projeto desenvolvido durante a formação Java da Alura.

## Objetivo
Aplicar conceitos de Programação Orientada a Objetos em Java.

## Conceitos aplicados
- Classes e Objetos
- Métodos e atributos
- Encapsulamento com atributos privados e métodos de acesso (getters e setters);
- Herança por meio da classe base Titulo;
- Polimorfismo para tratamento de diferentes tipos de conteúdo;

## Tecnologias utilizadas
- Java
- IntelliJ IDEA
- Git
- GitHub

## Sobre o projeto
O ScreenMatch simula uma plataforma de gerenciamento de conteúdos audiovisuais, permitindo o cadastro e manipulação de filmes, séries e episódios.
A aplicação possibilita registrar informações sobre títulos, realizar avaliações, calcular médias, estimar o tempo total de reprodução e gerar recomendações com base em critérios de classificação.
