# ScreenMatch
Projeto desenvolvido durante a formação Java da Alura.

## Sobre o projeto
O ScreenMatch simula uma plataforma de gerenciamento de conteúdos audiovisuais.
Inicialmente, o projeto foi desenvolvido para praticar conceitos de Programação Orientada a Objetos, permitindo cadastrar filmes, séries e episódios, realizar avaliações, calcular classificações e gerar recomendações.
Ao longo do desenvolvimento, o projeto foi expandido para incluir recursos de ordenação, comparação de objetos e gerenciamento de listas utilizando as principais estruturas da Collections Framework do Java.
Posteriormente, o sistema foi expandido para consumir dados reais da API OMDb, realizar conversão de JSON para objetos Java, tratar exceções personalizadas e persistir informações em arquivos JSON.

## Conceitos aplicados
## Programação Orientada a Objetos:
- Encapsulamento
- Herança entre classes
- Polimorfismo
- Sobrescrita de métodos
- Construtores
- Associação entre objetos

## Collections Framework:
- Utilização de ArrayList
- Ordenação de listas com Collections.sort()
- Ordenação personalizada utilizando Comparator
- Implementação de Comparable
- Iteração de coleções com for-each
- Manipulação de listas genéricas

## Consumo de API
- Integração com a API OMDb
- Busca de filmes pelo terminal
- Consumo de API REST utilizando HttpClient
- Conversão de JSON para objetos Java utilizando Gson
- Utilização de Records para representar dados recebidos da API
- Armazenamento dos resultados das buscas

## Persistência e Tratamento de Erros
- Geração de arquivos JSON
- Escrita de arquivos utilizando FileWriter
- Tratamento de exceções
- Criação de exceções personalizadas
- Validação de dados recebidos da API
